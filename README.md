# Rocket Cowboy

## Project Description
Rocket Cowboy is a web-based 2D game built with HTML5 and JavaScript. You play as a cowboy battling enemies with a super-powered weapon, which comes with a bit more recoil than expected.

## Tech Stack
- **HTML5** – Structures the web page and hosts the game.  
- **JavaScript** – Core game logic, including player movement, physics, and interactions.  
- **Phaser** – Primary game framework for 2D game development.  
- **Matter.js** – Physics engine handling collisions, gravity, and movement.  
- **Spine** – 2D animation tool for character and object animations.  
- **PIXI.js** – Rendering engine for fast and efficient 2D graphics.  
- **Base64 Encoding** – Assets are embedded directly in the HTML for simplified distribution.
